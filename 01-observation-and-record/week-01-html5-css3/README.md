# Experiment 01 – Responsive User Registration Form

## 📑 Basic Information

- **Experiment No:** 01
- **Date:** /07/2026
- **Title:** Creating a Responsive User Registration Form using HTML5 and CSS3

## 🎯 Objective / Aim

- To design and implement a responsive user registration webpage using HTML5 and CSS3.

## 🛠️ System Requirements

### Hardware
- Processor: Core i5
- RAM: 8 GB
- Storage: 256 GB

### Software
- Operating System: Windows 11
- Code Editor: VS Code
- Browser: Google Chrome

## 📐 Architecture / Design

The webpage consists of a registration form designed using HTML5 and styled using CSS3.

### Flow

User
↓
Registration Form
↓
Enter Details
↓
Submit Form
↓
Display Output

## 💻 Source Code

### HTML

The main HTML file is:

`src/index.html`

### CSS

The styling file is:

`src/style.css`

The HTML file defines the structure of the registration form, while CSS is used to provide styling and responsive design.

## 🧪 Compilation / Execution Steps

1. Open the project folder in VS Code.
2. Open `src/index.html`.
3. Run the HTML file using a browser.
4. Enter the required user details.
5. Click the Submit button.
6. Verify the displayed output.
